# 纯前馈控制器实验总结

## 实验范围

本次总结覆盖两个纯前馈控制实验目录：

- 纯前馈 out100：`experiment_results/feedforward/final_guarded_out100_r50x3/`
- 纯前馈 out200：`experiment_results/feedforward/final_guarded_out200_r50x3_retry/`

两个实验均使用 `Qwen2.5-7B-Instruct-AWQ`，对比策略为：

- `baseline_350w`：prefill 和 decode 均使用 350W。
- `ff_decode_tbt_guarded`：prefill 仍为 350W，decode 阶段按 query count 桶使用固定功率上限。

纯前馈 decode 功率映射在 out100 和 out200 中一致：

| Query count | Target input tokens | Decode scheme |
|---:|---:|---|
| 8 | 225 | `fixed_decode_190` |
| 16 | 504 | `fixed_decode_190` |
| 32 | 1581 | `fixed_decode_190` |
| 64 | 2175 | `fixed_decode_205` |
| 96 | 11106 | `fixed_decode_205` |
| 128 | 22873 | `fixed_decode_210` |

每个输出长度包含 6 个 query count 桶、2 个策略、3 次 full repeat；每个桶每次 repeat 采样 50 条请求。因此每个输出长度下每个策略共有 900 个样本，out100 与 out200 合计每个策略 1800 个样本。

## 总体结论

纯前馈控制可以在较小的延迟代价下稳定降低 decode 阶段能耗。两个输出长度合并看，按 query 桶非加权平均，能耗降低 11.25%，平均功率降低 14.74%，TBT 增加 4.08%，E2E 增加 4.24%。若按各桶总能耗加权计算，整体节能为 11.75%。

out200 的节能效果略强于 out100，且延迟代价基本相同：out100 平均节能 10.63%、TBT 增加 4.11%；out200 平均节能 11.88%、TBT 增加 4.05%。这说明输出更长时，decode 功率控制覆盖的执行时间更长，节能收益更明显。

## 结果解读

1. 纯前馈控制的收益稳定。两个输出长度下所有 query 桶均为正节能，没有出现能耗回退；TBT 增幅集中在 3.65% 到 4.81%。
2. 固定 decode 功率桶已经覆盖主要负载差异。Q=8、16、32 使用 190W，Q=64、96 使用 205W，Q=128 使用 210W；该映射在 out100 和 out200 中都能维持约 4% 的 TBT 代价。
3. out200 的节能更充分。out200 平均节能比 out100 高 1.26 个百分点，而平均 TBT 增幅略低 0.06 个百分点，说明输出更长时，decode 降功率带来的能耗收益更能摊薄 prefill 与固定开销。
4. 主要代价体现在整体完成时间。E2E 增幅在 out100 为 4.30%、out200 为 4.17%，与 TBT 增幅基本一致；因此当前控制器适合以约 4% 延迟换取约 11% 到 12% 能耗下降的场景。
